# 學生晤談助理

用 LINE 官方帳號和 Google 日曆提供學生晤談預約。學生先登記姓名，再從老師開放且日曆有空的時間選擇。確認後會再次檢查空檔，寫入日曆並發送結果。固定晤談或已預約的活動撞期時，可提醒學生重選時段，或由老師接手。

## 從哪裡開始

1. 決定預約對象、開放時段、晤談長度、可預約日期範圍和需要老師接手的情況。
2. 準備自己的 LINE 官方帳號、可授權的 Google 日曆及 Cloudflare 帳號。準備一份獨立的測試日曆和測試帳號。
3. 參考 [部署和試跑](docs/deployment.md) 與 [日曆設定範例](calendar-profile.example.json)。若交給 AI 協作，請它先讀 [AGENTS.md](AGENTS.md)。
4. 以 Node.js 24 或以上版本執行 `npm test`。測試使用記憶體資料庫和模擬的 LINE、Google 服務。

## 預設行為

- 時區為台灣。一般預約從明天起連續七天，每次 30 分鐘。每週開放時段定義在 [src/time.mjs](src/time.mjs)。
- 加入官方帳號的好友可登記姓名並預約。固定晤談依設定的 Calendar 重複事件系列 ID 辨識，每次改期只更新受影響的單次活動。
- 老師開啟衝突監控後，會檢查未來 45 天。學生選「以上時間都不行」時會通知老師，並告知學生也可以下週再預約。
